# 界面与按键

## 布局

宽终端使用会话侧栏与聊天区双栏布局；空间不足时自动切换为紧凑布局。设置、错误详情、
代码查看器和压缩预览都使用独立 Overlay，Overlay 打开后会接管焦点和光标。

```text
┌──────────────────────────────────────────┐
│ Header：会话标题                         │
├──────────────┬───────────────────────────┤
│ 会话与设置    │ 消息与 Markdown            │
│              ├───────────────────────────┤
│              │ 多行输入框                  │
├──────────────┴───────────────────────────┤
│ Footer：模型 | 上下文 | tok/s | 状态      │
└──────────────────────────────────────────┘
```

## 默认按键

| 位置 | 按键 |
| --- | --- |
| 输入框 | `Enter` 发送；`Ctrl+O` 换行；`Ctrl+P` / `Ctrl+N` 浏览输入历史 |
| 文本编辑 | `Ctrl+左/右` 按词移动；方向键配合 `Shift` 扩展选择；`Ctrl+A` 全选；`Alt+C` 复制 |
| 焦点 | `Tab` 在侧栏与输入区之间切换 |
| 鼠标 | 点击过程摘要查看详情；滚轮浏览消息或所在列表/详情；点击输入框定位、拖动选择；点击会话或设置入口打开 |
| 消息区 | `PageUp` / `PageDown` 浏览历史；回到底部自动跟随新输出；`F3` 打开过程详情 |
| 过程详情 | `Tab` 切换步骤列表/详情焦点；方向键和翻页键导航；`[` / `]` 切换参数、结果、原始页；`c` 复制完整内容；`Esc` / `F3` 返回 |
| 侧栏 | 上/下或 `j` / `k` 选择；`Enter` 打开；`n` 新建；`r` 重命名；`/` 搜索；`d` 删除；`s` 设置 |
| 会话搜索 | 输入关键词筛选；上/下选择；`Enter` 打开；`Esc` 关闭 |
| 模型切换 | `Alt+M` 修改会话默认模型；`Ctrl+M` 只修改下一轮模型；列表按 Provider 分组，`↑` / `↓` 跨组选择，`Tab` 跳转 Provider |
| Slash 命令 | `/models` 打开会话默认模型列表；`/mcp` 打开已配置 MCP Server 列表 |
| 代码查看器 | `F4` 开关；`[` / `]` 切换代码块；方向键滚动；`c` 复制 |
| 错误详情 | `F2` 开关；上/下或 `PgUp` / `PgDn` 滚动 |
| 上下文压缩 | 输入 `/compact` 预览并按 `Enter` 确认；输入 `/undo-compact` 撤销最近一次压缩 |
| 全局 | 生成中 `Esc` / `Ctrl+C` 取消；空闲时 `Ctrl+C` 退出 |

聊天编辑器的八个命令键可以在设置页面或 TOML 的 `[keybindings]` 中修改。程序保存时会
检查重复绑定、普通文本拦截和全局保留键冲突。

## 查看工具调用结果

消息中的“▸ 思考 · N 项工具 · 已完成”是过程摘要。点击这一行，直接打开对应步骤的
过程详情；也可以按 `F3`，再用上/下选择工具步骤。工具已经返回内容时，默认显示“结果”页。

- 点击“参数 / 结果 / 原始”标签，或用 `[` / `]` 切换。
- 鼠标放在详情上滚轮浏览内容；放在步骤列表上滚轮选择步骤。
- 按 `c` 复制当前页的完整内容，包括没有显示在屏幕上的部分。
- 窄屏点击步骤后进入详情，点击“列表”返回步骤列表；`Tab` 也可切换。
- 点击“关闭”或按 `Esc` / `F3` 返回聊天，保留草稿与消息阅读位置。

消息区与侧栏同样支持滚轮；点击会话直接切换。输入框点击定位光标，拖动选择文本，
支持中文、emoji、组合字符和自动换行，之后可用 `Alt+C` 复制选择。设置表单、模型列表
和其他弹窗继续使用各自的键盘操作，弹窗打开时鼠标不会操作背后的聊天区域。

程序默认接收终端鼠标事件。需要终端自身的文本选择时，多数终端可按住 `Shift` 再拖动；
具体修饰键以终端设置为准。

## Markdown 与代码

助手正文按 Markdown 增量渲染，支持标题、列表、引用、强调、行内代码和 fenced code
block。代码查看器用于查看当前会话中的代码块，并支持独立滚动与 OSC 52 复制。

Markdown 外观取决于终端的字体、Unicode 宽度与 truecolor 支持。相关边界见
[TUI 与终端兼容矩阵](/tui-compatibility)。

## 主题

设置中的“外观”页面提供三套主题：

| 主题 | 特点 |
| --- | --- |
| Vanguard | 青绿主色、琥珀强调的默认深色主题 |
| Carbon | 冷灰背景与蓝色主色的深色主题 |
| Paper | 高对比浅色主题 |

“启动动画”控制首次播放后是否每次启动重播 BT 开场；第一次会完整播放降落、震屏、
起身、点亮传感器和面板展开，后续播放可按 Esc 跳过。
“空对话泰坦”控制无历史且无任何草稿时显示 BT；开始输入即隐藏，清空草稿后恢复。
对应配置为 `show_titan_on_startup` 和 `show_titan_when_idle`。

“输入框星空”由顶层 `whimsy` 控制，默认关闭。开启时淡入 1 秒，随后在输入框空白区域
持续闪烁，打字、粘贴和已有草稿都不会让它消失。终端失焦、切换侧栏或打开弹窗时暂停重绘，
返回输入框后继续。设置中按 `Ctrl+S` 保存立即生效，直接编辑配置文件约 1 秒内生效。
关闭配置后用 75ms 淡出并停止动画。
